# NiszaOS Launcher for Android TV 📺💎

A premium, high-performance, open-source Android TV launcher built from scratch by **NiszaBisza Corporation**. 

NiszaOS is engineered specifically to eliminate ad-bloated layouts, privacy-invasive tracking, and low-effort "AI slop" templates. It brings a luxury, human-crafted visual experience heavily inspired by high-end glassmorphic design guidelines edited with ai , fully optimized to run fluidly at 60 FPS on older hardware like **Android 9 (API 28)** and **TCL TVs**.

---

## ✨ Key Features

### 💎 Ultra Liquid Glass Materials (Backported to API 28)
Real-time backdrop blurring can destroy the performance of affordable TV processors. NiszaOS utilizes an advanced, hardware-accelerated dual-layer emulation engine. It features organic top-left light reflections (Specular Rim) and subtle quartz-like frosting textures without lagging your device.

### 🎯 Focus Motion & Remote Physics
Ditch flat, boring rectangles. Every selection card in NiszaOS uses continuous superellipse curves (Squircle geometry) that dynamically react to your TV remote. When focused, tiles softly scale up and cast multi-layered ambient shadows to create true physical depth.


### 🛰️ Native AirPlay Destination Shortcut
Integrate your favorite casting utilities seamlessly. The built-in AirPlay menu shortcut scans your system for receivers (such as AirScreen or CastReceiver), links your preferred app, and updates its summary dynamic label. Click it on the home screen to cast instantly.

### ⚙️ TCL Hardware Failover & Keep-Alive
Aggressive stock software managers like to kill third-party launchers in the background. NiszaOS includes system boot and screen-state receivers that shield the app from being force-closed, alongside custom TV settings intent overrides designed specifically to bypass TCL system restrictions.

## 🛠️ Installation & Setup

1. Go to the **Releases** section on the right side of this repository and download the latest encrypted `NiszaOS-release.apk`.
2. Transfer the file to a USB flash drive and plug it into your Android TV / TCL TV, or sideload it using an app like *Send Files to TV*.
3. Use a file manager on your TV to open and install the `.apk` file.
4. Launch the app, navigate to NiszaOS Settings, and click **"Set as Default Launcher"**. Select NiszaOS and choose **"Always"**.
